# 首版验收记录

日期：2026-10-11，Asia/Shanghai。测试运行在本机 macOS / Darwin 27.0.0、Apple M3（8 CPU）、16 GiB 内存、arm64，Node.js 24.21.0，pnpm 11.25.0。没有运行公网部署，也没有把本机结果解释为公网服务器容量。

## 工程、规则与联机

- TypeScript 严格类型检查、格式检查和 Vite / esbuild 生产构建通过。
- 16 项规则、内容、持久化、备份和真实 WebSocket 测试通过。
- 4 张地图 × 2/4/6 席位 × 4 固定随机种子，共 48 场完整机器人对局，46,243 个规则动作；逐动作检查资金非负且为整数、唯一归属、建筑/抵押约束、阶段可推进与最终胜者。
- 30 张卡牌逐个执行合法目标，验证团队免租/结算、拍卖顺序、交易原子交换、偿债与破产。
- 2/4/6 真人席位的真实套接字流覆盖准备、启动、重复消息、同时操作、过期版本与越权拒绝、观众私有手牌过滤。
- SIGKILL 后重启、原席位凭证恢复、已确认动作去重、房主移交、无人重连时的后台托管推进通过。
- 在交易、拍卖、岔路阶段保存/关闭/重开数据库，资产和待处理决策一致。在线备份包含已提交 WAL 数据，恢复后席位与去重结果一致，备份权限 600。

## 30 分钟负载运行

运行区间：22:10:03–22:40:05。20 房间、120 个持续联机席位，每房 6 人，轮流提交真实游戏动作，覆盖四张地图和自由/团队模式。同期进行了构建和浏览器测试，因此数字包含本机竞争负载。

| 指标 | 结果 |
| --- | ---: |
| 实际运行时间 | 1,801.61 秒 |
| 接受的规则动作 | 138,496 |
| 拒绝动作 | 6 |
| 意外断线 / 进程崩溃 | 0 / 0 |
| 个性化状态视图 | 832,392 |
| 动作确认 P50 / P95 / P99 | 34.3 / 70.2 / 102.7 ms |
| 健康检查 P95 | 110.0 ms |

原始脚本对任何拒绝都返回失败，因此首次运行的 **exit code 为 1**。逐条查询数据库后，6 次均为安全拒绝过期状态版本；没有其他业务错误。独立审计 20 个快照的资产约束与持久化事件尾通过，数据库接受动作数与报告一致。脚本已将安全版本冲突单独记录，其他错误、断线或未建立完整负载仍返回失败。

停止时 18 场已结算，2 场尚未执行期限后的下一次定时 tick。将数据库复制到隔离目录并由最终服务恢复后，20 场全部结算，不需要真人先重连。

持续运行开始于开发基线构建；随后补充了输入边界与恢复后台房间等保护。最终服务端另做相同 20 房间 / 120 席位的 120 秒补测：9,439 个动作，零拒绝、零断线，P95 确认 57.9 ms，采样 RSS 最大 251.3 MiB，采样 CPU 最大 34.1%。最终服务端 bundle SHA256 为 `929ca1dba2906734b10841ea3be9e94110acac431b81e5b5c30f029a04fad63a`。

原始数据：`artifacts/load-1791727803750/result.json` 与 `audited-result.json`；最终补测：`artifacts/load-1791729732592/result.json`。私有对局数据与数据库不提交 Git。可用 `pnpm exec tsx scripts/audit-load.ts <运行目录>` 重做资产与事件审计。

编译包已在独立目录执行 `pnpm install --prod --frozen-lockfile` 并使用 Node.js 24 启动：首页与健康检查返回 200。在线 SQLite 备份/恢复已测试。

提供 systemd 服务、Caddy 同源 HTTPS/WSS 配置、环境变量模板、数据库备份、升级/回滚与停机步骤。当前环境是 macOS，systemd 与 Caddy 的实际 Linux 启动、域名 TLS 签发、目标机器压测和两个不同网络的完整对局由部署者按 `docs/DEPLOY.md` 执行；这些项目尚未标为完成。
