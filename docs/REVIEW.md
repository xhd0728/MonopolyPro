## 当前交付

- 四张地图统一为真实国家主题：世界环游、海洋航线、欧亚快线、丝路商旅。分别保留环路、轮渡、岔路、周期商路机制。
- 桌面为路线环形棋盘，手机为编号一致的四列折线棋盘；地图内滚动跟随回合，避免把整个页面滚动到不可操作的位置。
- 玩家卡片直接显示现金、存款、净资产、地产/建筑/手牌数量、队伍和联机/托管状态。点击查看国家地产、租金、待付债务与净资产公式。
- 地产信息弹窗提供费用、归属、应付租金预估、道路与经营入口。等候回合可查看自己的手牌效果、所有公开资产与图鉴。
- 银行支持自定义整数金额，交易和竞价明确显示条件与校验原因；移动端底部保留本回合主操作和资产/动态入口。

规则动作继续先事务落盘，再确认和广播。地图的 mapId 和节点身份保留，名称与视觉变化不重写已有对局资产。国家名称仅作为主题标签，路线、价格和地产组为游戏设计。参考项目没有直接复制代码或地图素材。

## 验收依据与边界

18 项自动化测试通过，含 48 场完整模拟；四组真实 Chromium UI 流程通过，覆盖邀请、买地/建设、交易、岔路/拍卖、刷新/重连、资产、教学和结算。当前服务端 20 房间/120 席位短时补测接受 9,419 个动作，无拒绝或意外断线。详细环境和原始结果路径见 [验收记录](VALIDATION.md)。

本轮没有发现仍阻塞本地使用的已知问题；这不等于所有规则组合或设备均已验证。真实手机浏览器、Linux systemd/Caddy、TLS 与不同公网网络验收由部署者执行，见 [部署步骤](DEPLOY.md)。

## 一屏界面与 AI Review（2026-10-12）

- 对局使用固定视口高度。桌面为玩家列 / 完整棋盘 / 操作区，较窄桌面将玩家卡片排列在上方，手机使用六人概览、完整路线与固定主操作。详细信息进入弹窗或面板，游戏页面不依赖整页滚动。
- 独立骰子组件渲染服务器点数、总和、前进格数和角色加成，显示等待/掷骰状态，并遵守减少动画设置。
- 每次关键动作出现视觉提示及后果说明。棋盘中区提供当前阶段和下一步说明；玩家资料新增最近行动，动态面板保留连续日志。
- 操作、资产、动态、聊天统一在同一面板。去掉重复余额区域以保留手牌空间；资产权威值仍由玩家卡片和明细显示。
- 修复手机抽屉覆盖交易弹窗、自动决策结束后操作面板不可见，以及窗口变窄后骰子消失等检查中发现的问题。标准建设费与实际角色费用的标签含义明确。
- LLM 从合法候选中选择，客户端不能指定模型动作或读取 API 密钥。并发上限、超时/格式回退、过时结果保护、停机取消和持久化检查均通过。真实接口已完成服务调度与落盘；模型质量与更多真实模型组合未做大规模评价。

检查结果见 [当前验收](VALIDATION.md)，配置见 [服务端 AI](AI.md)。
