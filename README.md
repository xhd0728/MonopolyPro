# MonopolyPro · 富翁之旅

独立服务端裁定规则的中文浏览器大富翁。2–6 人或机器人，单颗六面骰，四张 36 格（10×10 环线、24 国 8 个地产组）国家路线地图，四角为起点、拘留所、免费停车场和遣返；六个角色、30 张原创卡牌；支持邀请房、密码、观战、自由/快速/团队战、刷新恢复与断线托管。

玩法上还有机会卡与命运卡各 16 张（抽卡时全场翻牌展示）、每轮一条世界新闻、看得见的追赶机制（追赶补贴、环球补助、按净资产计税、落后者抽两张取优），以及等待时的表情互动和免费的「猜一猜」点数竞猜。轮到谁、谁买了什么、每个人资金的增减都会对全场醒目提示，轮到你时还会给出下一步建议。

房主可以选择地图大小（标准 36 格或大地图 44 格）、结束方式（默认 16 轮，也可以限时或「净资产先到目标」，最后阶段进入租金 ×1.5 的终局冲刺），以及玩家操作时限（默认不限时；机器人最多思考两分钟）。玩家可以随时改名、开启挂机托管，也可以随时和任何人交易（支持多块地产、估值提示和还价）。顶部显示 Ping，桌面支持快捷键（空格掷骰等），音效可以在设置中关闭。局末纪念册给出每个人的统计和称号。

卡牌经济以随机为主：卡牌市场每回合只能花 150 盲抽一张（稀有卡更难抽到），新得到的卡下回合才能用，每回合最多用一张，手牌上限 5 张，租金护盾最多持有 1 次。空地默认只有停在上面的人能买（拍卖是房主可开的选项）。对手之间的交易必须双方都付出、价值差距不超过一倍，避免送钱和做局；后手玩家多拿一点起始现金。电脑端右下角常驻「实时动态」，最新的在最上面，机会卡、命运卡、交易和机器人的决策理由都会留在那里。LLM 机器人以「观察 → 调用只读工具 → 决定」的循环思考，并有多层兜底。

对局采用一屏桌游式布局：海洋棋盘中央显示骰子、当前步骤与主操作，棋子沿路线逐格跳动，手机与桌面使用同一块方形棋盘。规则要点见游戏内「规则图鉴」，本轮调研与平衡数据见 [调研](docs/RESEARCH.md) 与 [验收记录](docs/VALIDATION.md)。

## 本地运行

使用 **Node.js 22.16+（22.x）或 23.8 及以上版本（包括 24）** 和 **pnpm 11.25.0**。保留最低版本是因为服务端使用内置 SQLite 与在线备份接口，不限定只能使用 Node 24，也不限制更新主版本：

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm build
pnpm start
```

打开 <http://127.0.0.1:8788>，创建房间；第二个浏览器或独立浏览器配置可加入同一房间。一个浏览器配置的多个窗口会恢复同一游客席位，后进入的窗口接管该席位。

开发时分别运行 `pnpm dev` 与 `pnpm dev:client`，前端在 <http://127.0.0.1:5173>。`pnpm start` 自动读取 `dist/client`，与 API / WebSocket 同源。

启动时自动读取本地 `.env`。可选的服务端 LLM 机器人配置见 [AI 文档](docs/AI.md)，房主在房间选择规则或 LLM 策略；API 密钥不会发给浏览器。

`pnpm test` 验证规则、真实 WebSocket、恢复和模型回退。先构建服务端，再运行测试。`pnpm test:ui` 验证浏览器流程；`pnpm test:load` 启动隔离服务并进行 20 房间 / 120 席位 / 30 分钟测试。产物保存在忽略的 `artifacts/`。

仓库的 [自动检查与依赖更新](docs/CI.md) 覆盖格式、类型、构建、规则模拟、浏览器流程、依赖漏洞和 CodeQL；Dependabot 定期提交依赖与 Action 更新 PR。[Monopoly 求解器调研](docs/SOLVERS.md) 说明公开研究的适用范围与本项目的策略评估方向。

## 工程结构

- `packages/shared`：共享契约与输入校验。
- `packages/content`：原创地图、角色、卡牌配置。
- `packages/engine`：纯规则引擎与不依赖外部模型的机器人。
- `apps/server`：Colyseus 房间、HTTP、SQLite WAL 事务持久化。
- `apps/client`：React / HTML / SVG 二维棋盘，桌面环路和手机折线路线；玩家资产由服务端计算。
- `docs`：来源、架构、阶段验收。

恢复凭证只保存在本机浏览器；对手和观众不接收私有手牌。每个动作携带 UUID 与状态版本；确认前，将状态、事件和去重结果原子写入数据库。

公网部署、备份和回滚见 [部署文档](docs/DEPLOY.md)，检查结果见 [验收记录](docs/VALIDATION.md)，本轮界面与规则 review 见 [Review 记录](docs/REVIEW.md)。编译包只需安装生产依赖并运行 `pnpm start`；工程检查请在源码目录执行。公网部署和真实外网验收由部署者执行；本地测试不代表已上线。

## 第三方素材

Windows 上的 Chrome / Edge 不带彩色国旗 emoji，会把国旗显示成「CN」这样的字母。客户端在检测到缺少国旗时，会加载 [country-flag-emoji-polyfill](https://github.com/talkjs/country-flag-emoji-polyfill)（MIT）随包分发的国旗字体；字体图案来自 [Twemoji](https://github.com/twitter/twemoji)，按 [CC-BY 4.0](https://creativecommons.org/licenses/by/4.0/) 使用。字体自托管、只覆盖国旗码位，已有国旗 emoji 的系统不会加载。
